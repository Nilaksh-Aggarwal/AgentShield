# Defect and engineering findings matrix

Defects found during the project, from repository evidence only (docs/PROGRESS.md, ADRs, regression tests). A finding
is listed as a defect only when the evidence shows wrong behaviour; external conditions and deliberate design changes
are listed separately. "Regression test" names the test that fails on the defective code where the repository records
it (mutation checks in PROGRESS.md).

Status: **Fixed** (fix and regression test in the repository), **Open** (known, not fixed), **Mitigated** / **Deferred**
(not fixed, but the harm is bounded; see the note), **Partly fixed** (the note says what remains).
