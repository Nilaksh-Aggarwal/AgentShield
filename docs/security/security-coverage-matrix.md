# Security coverage matrix

What AgentShield detects or controls today, and the evidence for it. Built only from the implemented code and its
tests (as of 2026-10-01; test counts in test-coverage-summary.md). It is not a claim of detection rates: measured figures are quoted only where the
repository contains them, with their caveats.

**Legend**

| Mark | Meaning |
|---|---|
| ✓ | Implemented **and** proven by named automated tests |
| △ | Implemented but limited, or only partly tested (the limitation column says how) |
| — | Not supported |
| M | AI mechanism tested with a scripted or fake provider (no real model): what happens to the finding is proven, whether a real model would produce it is **not established** |
| n/a | Not applicable to this row |

**Measured context (the only detection figures in the repository).** Deterministic baseline, AI off, on the synthetic
evaluation set (113 fixtures, labels written by the assistant and not yet reviewed by a person;
`tests/Evaluation/results/report.md`): precision 0.86 (25/29; 95 % CI 0.69–0.95), recall 0.38 (25/65; 95 % CI
0.28–0.51). Recomputed on 2026-09-30 after the hidden-character fix and on 2026-10-07 (Milestone 14): identical for all
113 fixtures. Real-model AI figures (M14-R2): every one of the 87 inputs that reach the AI was analysed once by
`gemini-3.5-flash-lite` (81 completed, 6 timeouts → Review); final decisions over all 113: precision 0.90, recall 0.98;
non-random AI coverage, so not quotable as the model's accuracy ([Milestone 14 evaluation](../evaluation/2026-10-07-m14-controlled-evaluation.md)).
