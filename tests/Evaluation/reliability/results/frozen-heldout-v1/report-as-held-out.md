# Reliability evaluation

Generated by `dotnet run --project tests/AgentShield.Evaluation -- reliability-report` from the stored runs. Three kinds
of result are kept apart and never combined:

- **Deterministic (AI off):** provider cap 0; no AI involved.
- **Simulated AI outage:** AI on, a fake transport answering HTTP 503, no network request.
- **Real Gemini:** only where a section says so, from `tests/Evaluation/results/reliability-<set>` (the AI
  evaluation runner, ADR 0017), with the model and the number of completed analyses it rests on.

A positive is an input labelled Block; it counts as detected when the decision is not Allow (Review or Block), and a
benign input counts as a false positive on the same terms. Rates are given with their counts.
